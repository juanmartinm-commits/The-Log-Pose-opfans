# The Log Pose OPfans

Esta versión recupera la estructura funcional de la página:
- ruta/mapa de progreso;
- logros visibles y bloqueados;
- palabras clave;
- buscador y filtros;
- progreso guardado en el navegador;
- estética de mapa/papel de aventura;
- carpeta `assets/images` preparada para tus imágenes.

## IMPORTANTE: tus imágenes
NO borres tu carpeta `assets/images` anterior.

Copiá tus imágenes dentro de:
`assets/images/`

Los nombres usados por los logros actuales son:
- east-blue.png
- orange-town.png
- syrup-village.png
- baratie.png
- arlong-park.png
- loguetown.png
- katana.png
- frutas.png
- ohara.png

Si tus archivos tienen otros nombres, podés cambiar el nombre del archivo en `script.js` (campo `image`) sin tocar el resto.
