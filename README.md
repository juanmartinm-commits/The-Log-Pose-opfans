# The Log Pose OPfans

Tracker estático preparado para GitHub Pages.

## Firebase
1. Crear un proyecto Firebase.
2. Activar Authentication > Google y Email/Password.
3. Crear una Web App.
4. Copiar la configuración en `firebase-config.js`.
5. Agregar tu dominio de GitHub Pages en Authentication > Settings > Authorized domains.

Mientras Firebase no esté configurado, el botón **Modo demo** permite probar el tracker localmente.

## Imágenes
Reemplazá los placeholders en `assets/islands/`, `assets/easter-eggs/` y `assets/achievements/`. Los nombres sugeridos están en `assets/IMAGE_LIST.txt`.

## GitHub Pages
Subí todos los archivos del ZIP al repositorio y activá Settings > Pages > Deploy from branch.
